# Slyy Mailr Project Book

One page with the spec, the wireframes, the backlog and the code analytics:
https://claude.ai/artifact/4QHky2pUAWPXuEztduLXyy (private). This folder is its source; keep it current with every release.

```sh
python3 docs/project-book/build.py      # reruns slyy-analytics, writes build/project-book/mailr-book.html
```

Then publish that file to the same artifact URL.

| Part | Source here | Update when |
|---|---|---|
| Spec | `spec.html` | Rarely; it is the original spec (the Docs version was deleted 28 Nov 2026). |
| Wireframes | `wireframes/*.dc.html` | Copies of the design canvas https://claude.ai/artifact/4uEdFGq4abjGre83GPsda3 (the canvas stays the place to edit them); re-copy after canvas changes. |
| Backlog | `backlog/backlog-source.html` (the `ITEMS` list) plus the status changes and new items in `build.py` | Every feature change and release. |
| Code analytics | generated by `Tools/slyy-analytics`; `data/review.json` (code review findings), `data/cleanup.json` (cleanup backlog) | Every release; after a code review or cleanup. |

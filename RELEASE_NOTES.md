Slyy Mailr 0.3.1 — default sender address

**Default sender**: in Settings → Mail → Sender addresses, mark one address (the account address or an alias) as
Default. New mails start from it, with its signature. Replies still go out from the address a mail was sent to;
mail that names none of your addresses (mailing lists, Bcc) is answered from the default.

**Esc closes Settings.**

Installed 0.2.1 or newer on the Mac? This update arrives by itself. Signed with Developer ID and notarized by Apple.

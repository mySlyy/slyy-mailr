Slyy Mailr 0.8.0 — tidier writing, sharper search

Writing
- To, Cc and Bcc: several addresses add cleanly as chips that wrap to the next line. Comma, semicolon, Return, a space after an address or a pasted list all work; Backspace deletes the last chip.
- Replies and forwards of HTML mail quote the original as HTML, and the plain-text part is clean text (no code or styles; a line break stays one, a paragraph two).
- Replies start with the cursor on the first line.
- Replies come from your sender address of the domain the mail was sent to, when no address matches exactly.
- Edit as New Message: any mail opens as a new one to change and send again (right-click or the "…" menu).

Reading and organising
- Search shows sender, recipient and subject hits first, mails that only mention the words below, each mail once, and the results stay put while new mail arrives. It searches as you type.
- Delete one message of a conversation and the rest stays open. ⌘⌫ moves the current message to the Trash; ⌘Z brings it back.
- Dragging mail onto a folder shows a small tag instead of the whole row, and the target folder lights up. A dragged conversation moves all its messages.

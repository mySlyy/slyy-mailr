Slyy Mailr 0.8.4 — booking link, sharper search, reliable undo

- Booking link: set your scheduling page in Settings → Calendar → Booking Link (e.g. https://meetly.rocket.re-cloud.io/yourname). In the writer, the calendar-clock button pastes it where the cursor is.
- Search: "quoted text" finds those words exactly in that order; other words can be anywhere. Case is ignored.
- ⌘Z brings back the last mails moved to the Trash, wherever you are in the main window.
- ⌘⌫, ⌘A and U work again after using the search field.

Slyy Mailr 0.5.0 — faster by keyboard

**Fetch mail**: a button next to the Inbox title fetches new mail right away; ⇧⌘N does the same (menu View → Fetch Mail).

**Conversations in their own window**: double-click a message in the list to open the whole conversation in a new window,
every message open, with Reply, Reply all and Forward under each one.

**Shortcuts**:
- ⌘R reply, ⌘A reply all, ⌘F forward (⌘A stays Select All while you type in a text field).
- ⌘+ and ⌘− make the text of mails bigger or smaller, ⌘0 back to normal. The size is kept.

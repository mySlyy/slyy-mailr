Slyy Mailr 0.8.1 — smoother writing and reading

- ⌘K inserts a link: the selected text becomes the link's label (link button in the writer too).
- Address suggestions: ↑/↓ move, Return or Tab takes the address.
- Scrolling works again over mails in conversations and in the writer.
- Click "n unread" above the list to see only the unread mail of the folder; click again for all.
- A folder renamed or deleted in another mail app no longer shows a server error: Mailr updates the folder list and opens the Inbox.
